# context-bar

A Claude Code mod that shows the context window, and stats about the current session, above the prompt.

## Language

**Working project**:
The repository or folder Claude Code is working in for this session. Not the mod's own repo.
_Avoid_: the project (ambiguous with this repo)

**Project tests**:
The pass/fail result of the working project's own test suite, as last seen in this session. Changes from project to project. Many projects never run tests, so the band leaves it out until a test run is seen.
_Avoid_: the mod's tests, test coverage

**Band**:
The stats shown beside the context bar: rate limits, project tests, busy time and turns.
